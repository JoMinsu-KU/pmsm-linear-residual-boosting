The v007 reference includes quantitative history summaries and protocol receipts, but excludes exploration documents, manuscript PDFs, and per-row measured-temperature or prediction-trajectory CSVs.

The v011 reference adds the final six figure assets in PDF, PNG, and SVG, saved JSON figure sources and per-profile summaries, 15,339 selected per-row trajectory records, and 75 initialization plot cells. The trajectory CSV contains selected measured-temperature and fitted-prediction values prepared for the illustrative figure; it is not the full upstream dataset or a model-training data bundle. Selection, alignment, model predictions, and summary calculations are project transformations.
