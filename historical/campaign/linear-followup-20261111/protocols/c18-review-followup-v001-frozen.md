# C18 외부검토 후속 통제 비교 — 실행 전 고정 v001

2026-11-11 KST. 사용자 지시: “좋아. 모두 진행해주고, 결과 보고해줘.”
이 문서는 새 학습·조건 분석·비용 측정 전에 고정한다. 기존 외부검토 대조 보고서의 필수 후속을 실행하며, 이전 후보·확인 실패·자료 노출·자원 사용량과 마감을 유지한다. 기존 v1.0 명세서는 당시 상태를 보존한다.

## 1. 질문, 기호와 판단 범위

주 질문: 같은 초기화·관측 정보·분할의 강한 대조에서도 선형 잔차 학습 L과 고정 평균 H의 이득이 남는가?
보조 질문: 관측 가능한 시작조건·기록 경과에 따라 그 이득은 어떻게 달라지고, H의 추가 계산 비용은 얼마인가?

P=선형33 ridge, R=P의 in-sample 잔차에 적합한 HGB, L=P+R, D=기존 FIT선택 D9 직접 HGB, H=(D+L)/2. 지표는 °C 단위 현재 rotor 온도 추정 오차다. 최초 rotor 정답·정답 이력은 예측 입력에 넣지 않는다. 분석 단위는 기록(profile)이며 seed·행·동일 기록의 초기화별 반복을 독립 사례로 세지 않는다.

주 추정량은 기존 각 역할집단의 profile-macro-RMSE와 짝지은 차이 RMSE(A)−RMSE(B)다. 음수이면 A가 낫다. 기존 주 지표를 바꾸지 않고 pooled-RMSE, 편향, 과소추정·최대오차, 모든 기록별 손익을 보조로 제시한다. pooled는 행 가중이며 불규칙 timestamp의 시간 가중이 아니다.

일률적 3% 문턱이나 새 유의성 문턱을 도입하지 않는다. 기존 데이터의 탐색적 효과 크기·분산·악화·측정 비용으로 판단한다. 작은 개선을 동등성 또는 무용성으로 바꾸지 않는다. 새로운 통계적 우월성/인과성/세계 최초/모든 모터 일반화는 주장하지 않는다.

## 2. 자료와 역할

기존 감사된 IPMSM FIT8 및 CAL3/PILOT3/CONF2, Paderborn FIT41 및 DEV14/CONF14를 그대로 쓴다. RWTH는 원형 모델의 CAL8/CONF10 진단·비용에 사용하며 특징/시간 필터가 다른 점을 유지한다. 모든 현재 자료는 이미 노출되었다. 기존 CONF 명칭은 역사적 역할이다.

원형, own_boundary, first_load의 기존 결과와 불리한 IPMSM 결과를 모두 보존한다. own_boundary는 각 경계 필터를 그 채널 최초 관측으로 시작하고 heating은0으로 시작한다. legacy 원형의 두 경계 필터는 ambient 최초값으로 시작한다. 이는 실제 rotor 초기 열 상태 추정 실험이 아니다.

최초300행을 제거하기 전에 모든 입력 이력을 필터에 사용한다. legacy FIT는300::5, 평가300:를 유지한다. 고정 특징33·span16/64/256/1024/4096·가중치·정규화·허용 입력·정답 접근은 기존 감사된 생성 절차와 같게 한다. 입력/모델/설정/코드를 해시로 잠근다.

## 3. 신규 own_boundary 강한 대조

각 legacy 자료의 기존 own D/P/L/H 모델과 예측을 재사용한다. 다음을 같은 own 입력에서 적합한다.

1. 직접 HGB200: 기존 residual과 동일15leaves×200 설정의 직접 타깃 대조.
2. 추가 용량 직접 HGB: 기존 사전 고정 split-capacity 규칙의 967iterations/IPMSM,1200/Paderborn. 실제 지연·학습비용이 동일하다는 뜻은 아니다.
3. 자유25 필터 특징 선형 prior(절편 포함26계수)+잔차200 및 기존 own D와의 고정50:50 평균. λ는 원 FIT에서 선택된 free25 값을 고정하고 재선택하지 않는다.
4. 기존 MSE MLP33→64→32→1, ReLU,200epochs, AdamW lr0.001/weight_decay1e-4, batch4096, 기존 legacy gradient clipping1, seeds2026111701/02/03. 원 학습 절차·FIT 정규화·profile-balanced 가중을 유지한다. 새 seed 선택·early stopping·held결과 기반 튜닝 없음.

신규 적합 합계는6HGB+2자유선형prior+6MLP다. λ/설정 탐색을 새로 하지 않는 **고정 설정 요인 비교**이며, 각 초기화에서 FIT-CV로 재최적화한 최선 성능 비교가 아니다. 이미 각 모델에 사용된 선택 비용·차이를 공개하고 이를 같다고 소급 주장하지 않는다. 원형 모델과 own 모델을 혼합해 우열을 판정하지 않는다.

자료/작업/seed별 별도 산출물을 쓰며 모델·전체 역할 예측을 먼저 잠근 뒤 별도 평가한다. 학습배열, 모델, HGB 트리 원소, MLP 초기/최종 가중치·학습 trace와 행식별자를 저장한다. MLP는 개별seed 지표와 seed별 지표의 평균/범위를 보고하고 seed 예측평균 모델로 바꾸지 않는다. 3seed가 일반화 정밀도를 보장하지 않는다.

## 4. 저장예측 조건 분석

원형54기록 및 초기화 변경72개 기록×조건의 기존 저장예측을 사용한다. 126개 반복 기록을126개 독립 사례로 취급하지 않는다. 모든 기존 역할별 macro/pooled/주기별 H−D,H−L,L−D를 계산한다. 기존 동일5개의 retained-row 경과 구간을 유지하며 물리 시간으로 부르지 않는다.

legacy 기록 i에 대해 δ_i=Tc_i(0)−Ta_i(0), a_s=1−2/(s+1), B_i=sqrt(mean_{s,t=300..N_i−1}[(a_s^t δ_i)^2])를 계산한다. B는 바뀐 냉각수 필터 입력의 RMS 크기이며 rotor 초기 온도 오차가 아니다. signedδ, 원행/평가행 수, B와 span별 B를 같이 공개한다. 원행 t를 평가 시작 후0으로 재설정하지 않는다.

ΔL=RMSE(L_own)−RMSE(L_original), ΔD=RMSE(D_own)−RMSE(D_original), I=ΔL−ΔD를 함께 보고한다. I<0만으로 L 자체 개선을 주장하지 않는다. 시작조건과 기록 길이의 공선성, 모델·FITscale 재적합을 명시한다. 모든 연속 관측값을 제공하며 사후 임계값·유리한 기록 제외·선택 규칙 적합을 하지 않는다. 자료/역할별 기술적 rank 상관은 n>=3 및 비상수에 한하고 p값/인과 증거로 쓰지 않는다.

## 5. 비용 측정

로컬 CPU 한 스레드에서 실제 저장 모델의 batch1 추론을 측정한다. 특징갱신·스케일링·각 모델/결합 계산을 포함한 streaming 범위와 모델만의 범위를 분리한다. 학습과 벤치마크는 동시에 실행하지 않는다. 대표성은 운영분포의 추정이 아닌 같은 입력열의 고정 비교다.

방법 순서를 교차하고 사전 warmup, 반복별·개별 호출 median/p95, 모델 serialization bytes 및 측정 가능한 메모리 범위를 보고한다. 실행 전 별도 비용 config에서 정확한 반복/기록 수를 고정한다. Python 데스크톱 CPU 수치를 임베디드 장치·하드 실시간 보장으로 바꾸지 않는다. 공유 특징은 결합 내 한 번만 계산한다. 모델만의 결과를 전체 추론시간으로 쓰지 않는다.

## 8. 결과별 판정

- L이 같은 조건의 강한 대조에 이점을 유지하고 H 추가 가치가 작으면 선형 잔차·초기화 중심으로 진행한다.
