# C18 후속 실행 환경 보충 — 신규 학습 전 고정

2026-11-11. 기본 설계 c18-review-followup-v001-frozen.md의 §7 중 모든 신규 적합을 CPU로 실행하고 신규 GPU를0으로 예상한 부분을 수정한다. 기존 MSE MLP의 실제 실행은 WSL CUDA였으므로 **같은 WSL/PyTorch/CUDA·FP32·결정성 설정으로 RTX4090에서 새 MLP6개를 순차 학습**한다. 입력 초기화 외에 학습 장치와 수치 절차가 달라지는 문제를 피하기 위한 실행 전 수정이며, 새 수치 결과를 보고 변경한 것이 아니다.

CPU HGB/ridge, 저장예측 분석과 독립 감사는 한 스레드로 실행한다. 실제 추론 비용 비교는 모든 학습 종료 후 CPU 한 스레드에서 측정하며, 학습장치와 배포측정장치를 구분한다. 원 모델과 새 모델의 동일 CPU 추론 구현·정확도 대조를 먼저 확인한다.

각 MLP 단계 cap900초, 최대6개이며 최대 예약 GPU1.57시간(각 종료 점검40초 포함)을 기존 누적량에 추가한다. 실제 사용량은 supervisor 전체 점유 시간으로 계상한다. 불가피한 수리도 기존 캠페인 상한과 같은 차단원인2회 한도를 유지한다. 기존600GPUh/1로컬GPU/마감/학습cutoff/저장한도는 늘리지 않는다. 이전의 신규GPU0h 문구는 예상치이며 실제 종료보고에는 실측을 쓴다.

기존 코드/학습 설정을 해시로 확인하고 seed·PCG64 순열·batch4096·학습200epoch·가중 MSE·AdamW·gradient clipping1·TF32금지·FP64전처리/FP32network를 유지한다. 실제 CUDA 가용성과 소유 프로세스 종료를 실행 전후 검사한다. 비교구성·지표·자료·판정기준은 기본설계와 같다.
