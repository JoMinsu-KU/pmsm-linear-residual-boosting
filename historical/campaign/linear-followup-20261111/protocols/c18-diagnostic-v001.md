# C18: 선형 잔차 모델과 직접 모델의 고정 반반 결합

사용자가 8.40% 개선된 선형33 잔차 HGB와 D9의 50:50 결합을 다음 후보로 지정했다. 이는 C17의 확인 성공으로 이름을 바꾸는 것이 아니라 결과를 보고 선택한 새 탐색 후보다. 기존 IPMSM, Paderborn, RWTH의 모든 평가 자료는 노출되어 있다. 이전 두 확인 시도와 오류 예산을 보존하며 새 유의성 검정이나 confirmed_candidate 승격을 수행하지 않는다. 논문화 가능성은 유효한 탐색 증거와 최근접 선행 대비 실용적 질문을 함께 판단한다. 작은 개선이나 기존 기법의 조합 자체를 탈락 이유로 삼지 않는다.

## 수학적 질문과 판정

운전 주기 i의 rotor 온도 y(°C)를 같은 인과 특징 x로 추정한다. D(x)는 학습 운전 주기 내 교차검증으로 고른 직접 HGB, L(x)=b+βᵀx+R(x)는 선형 ridge 추세에 학습 잔차 HGB를 더한 모델이다. 후보 H(x)=(D(x)+L(x))/2는 평가 정답 또는 별도 CAL 비중 없이 고정한다. 각 자료의 기존 FIT/CAL/PILOT/CONF 역할과 필터·warmup·센서 구성은 그대로 보존한다. 새 분석에서 CONF라는 과거 이름은 독립 확인을 뜻하지 않는다.

주 지표는 각 주기 RMSE를 동일 가중 평균한 macroRMSE이다. 전체 프레임을 합친 RMSE로 대체하지 않는다. 개선이 발생하는 조건과 악화의 수치적 원인을 구분한다. 모든 모터에서 이겨야 한다거나 3% 이상이어야 한다는 문턱을 추가하지 않는다. 그러나 더 단순한 방법이 모든 이득을 설명한다면 복잡한 결합 자체의 기여는 축소한다.

eD=D−y, eL=L−y일 때 주기별 정확한 항등식:

MSE(H)−MSE(D) = 0.5[MSE(L)−MSE(D)] − 0.25 E[(D−L)²].

오른쪽 두 항을 RMSE(H)+RMSE(D)로 나누면 주 지표 ΔRMSE의 정확한 기여를 얻는다(둘 다 0일 때 기여 0). 다시 주기별 평균을 낸다. 편향 제곱과 오차 분산·공분산을 추가 분해한다. 이 항등식은 새로운 이론이 아니며 물리적 인과 증명도 아니다. 오류가 큰 선형 전문가와 앙상블 보완 효과의 상대 크기를 설명하는 도구다.

## 첫 진단 실험: 새 학습 없이 저장 예측 검증·재계산

1. 세 자료의 모든 기존 평가 역할에 대해 저장 모델·예측·정답 출처 해시를 검증한다.
2. D9, direct200, 선형 ridge 단독, 선형+잔차 단독, 반반 결합, D9+선형 ridge 단독 반반, 기존 CAL 결합, D9+direct200 반반, D9+free25 반반을 가능한 동일 역할에서 비교한다. RWTH ridge 단독은 동결된 계수로 새로 계산한다. 누락된 조건은 누락으로 표시하며 다른 방법으로 대체하지 않는다.
3. 주기별 RMSE, 편향, 오차 공분산, 위 항등식과 평가에 남긴 행의 순서상 5등분 기여를 계산한다. 이는 동일 초 단위 구간이나 warmup 이전 전체 주기의 5등분이 아니다. IPMSM id10뿐 아니라 모든 주기를 기록한다. id10을 제외해 결과를 성공으로 바꾸지 않는다. 잔차 단계는 MSE(L)−MSE(prior)=2E[(prior−y)residual]+E[residual²] 항등식으로 따로 분해한다.
4. 온도·전류·절대속도·냉각수 조건은 FIT의 5/95 분위수로 낮음/중간/높음을 정의하고 FIT 최소/최대 범위 밖 비율도 기록한다. 학습 특징의 범위를 벗어난 비율 및 학습 정답 범위 이탈은 원인 후보를 좁히는 진단이다. 평가 정답을 이용한 조건은 배포 가능한 규칙이나 사전 예측 규칙으로 부르지 않는다.
5. 개선이 선형 추세 자체인지, 잔차 보정인지, 두 예측 경로의 평균인지 구별한다. CAL 비중을 재최적화하거나 새로운 승자를 같은 자료에서 확인했다고 부르지 않는다.

## 후속 실행과 중단

진단 후 원인을 구별할 수 있는 제한된 개입 또는 공정한 동일 용량 비교를 새 버전으로 고정하고 실행한다. 예: 같은 특징과 학습 샘플을 쓰는 직접 HGB, 선형 잔차 HGB, 반반 결합, 두 직접 모델 결합, 더 큰 직접 HGB. 대안 설명에 필요한 최소 실험을 우선하며 전체 재학습을 논문화 가능성 보고의 선행 조건으로 만들지 않는다.

선형 결합의 필요한 구성요소, 악화 조건, 강한 대조 대비 유효한 적용 범위, 최근접 논문과 구별되는 재현 가능한 실용적 질문이 함께 지지되면 PROMISING_PUBLICATION_DIRECTION으로 즉시 보고한다. 현재 자료의 작은 효과나 특정 p값만으로 게재를 보장하지 않는다. 중요한 대안 설명이 남으면 실험을 계속한다. 기여가 사라지면 그 이유를 보존하고 보고한다.
