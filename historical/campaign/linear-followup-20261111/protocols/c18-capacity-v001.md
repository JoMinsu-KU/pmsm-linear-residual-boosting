# C18 추가 트리 용량 대조 — 결과 확인 전 고정

목적: 선형 잔차 결합의 이득이 직접 모델에 더 많은 트리를 주는 것만으로 설명되는지 확인한다. 각 자료의 기존 FIT 및 인과 특징을 그대로 쓰고, D9의 학습 전용 교차검증 선택 설정을 유지한다. 오직 직접 HGB의 반복 수를 `Nnew=ND9+ceil[200*(15−1)/(LD9−1)]`로 늘린다. 이는 D9와 15잎·200트리 잔차 전문가의 **최대 내부 분할 수 합** 이상을 제공하는 고정 대조다. 실제 노드 수·실행시간·메모리가 동일하다는 뜻은 아니며 실제 노드 수도 별도 보고한다. 선형 계수의 연산과 특징 생성 비용을 포함한 동일 지연시간 대조는 아니다.

IPMSM/RWTH는 D9 7잎·500반복에 대해 967반복, Paderborn은 15잎·1000반복에 대해 1200반복이다. 나머지 loss,learning rate,L2,최소 잎 샘플 수,최대 bins,seed와 profile-balanced sample weight는 기존 직접 모델과 같다. 전체 FIT에서 한 번 학습한다. 재탐색·CAL/평가 정답을 이용한 선택은 하지 않는다. 기존 D9 및 direct200의 정확한 재현을 새 모델의 staged predict로 확인할 수 있는 범위에서 확인한다(D9 시점은 반드시 확인).

학습 샘플: legacy는 warmup300 이후 stride5, RWTH는 warmup0/stride5. 평가 행은 기존 파일의 행/원행 ID 그대로 유지한다. 세 자료의 모든 기존 평가 역할에서 새 예측을 저장하고 별도 계산으로 주기별/역할별 macroRMSE를 계산한다. CAL 역할도 기록하되 평가 성공으로 세지 않는다. 모든 결과는 C18 선정 후 탐색이다.

세 실제 새 적합만 수행한다. 첫 RWTH 실행으로 비용을 측정하고 나머지 실행 상한을 점검한다. 단계별 최대900초/신규1GB, 전체 기존 누적 한도와 새 마감을 지킨다. 트리 노드·훈련 배열/출처·스케일·예측을 저장해 독립 검증한다. 더 큰 직접 모델이 이기면 그 대안을 보존하고 선형 결합 기여를 축소한다. 이 대조가 뒤져도 최신 모든 방법 대비 우위를 선언하지 않는다.
